# dsh-mail-bridge

让 DeepSeek Harness 帮你收发 QQ 邮箱。

装好之后你不用记任何命令，直接对它说人话就行：

- “看看我最近收到什么邮件”
- “张三发过的那封带附件的邮件，附件存到桌面”
- “帮我给 li@example.com 写封信，附件用 D:\报告.docx”
- “明天早上九点把这封信发出去”

它会真的去你的邮箱里读、写、发。

---

## 一、它能做什么

| 你想干的事 | 背后的工具 |
| --- | --- |
| 发一封邮件，可带附件 | `mail_send` |
| 先写好一封信，让你过目再发 | `mail_draft` |
| 定个时间，到点自动发 | `mail_schedule` |
| 看最近收到了什么 | `mail_list` |
| 打开某一封读正文 | `mail_read` |
| 按发件人 / 主题 / 日期找邮件 | `mail_search` |
| 标成已读、加个星标 | `mail_mark` |
| 把信挪到别的文件夹 | `mail_move`（QQ 邮箱不支持，见下） |
| 把附件存到电脑上 | `mail_download` |
| 看邮箱里有哪些文件夹 | `mail_folders` |

## 二、安装（三个步骤）

**第 1 步：确认电脑上有 Python 3**

装插件本身不用 Python，但真正收发邮件的那部分是用 Python 写的。

打开命令提示符或 PowerShell，输入：

```bash
python --version
```

能看到类似 `Python 3.13.1` 就行。没有的话去 https://www.python.org/downloads/ 装一个，装的时候记得勾选 “Add Python to PATH”。

**第 2 步：装插件**

```bash
dsh plugin install dsh-mail-bridge
```

**第 3 步：填邮箱和授权码**（见下一节）

---

## 三、配置 QQ 邮箱

### 1. 拿到授权码

1. 浏览器打开 https://mail.qq.com 登录你的 QQ 邮箱
2. 点「设置」→「账号」（新版叫「账号与安全」）
3. 找到「POP3/IMAP/SMTP 服务」，把 **IMAP/SMTP 服务** 打开
4. 按提示生成一个 **授权码**，是一串 16 位字母，复制下来

> ⚠️ 授权码不是你的 QQ 密码。它是专门给第三方软件用的“临时钥匙”，可以随时在邮箱后台重新生成或作废。

### 2. 把授权码填进配置

打开这个文件（路径里的用户名换成你自己的）：

```
C:\Users\<你的用户名>\.dsh\profiles\desktop\cordis.patch.yml
```

在文件**最末尾**加上这几行：

```yaml
- id: mail-bridge
  name: dsh-mail-bridge
  config:
    user: 你的QQ号@qq.com
    pass: 刚才复制的授权码
```

保存，然后重启 DSH（或者让插件重新加载一次）。

### 3. 试试看

在 DSH 里说一句“看看我最近收到的邮件”，能列出邮件就说明通了。

### 换成别的邮箱

QQ 之外的邮箱（Gmail、163、公司邮箱等）也能用，把主机和端口一起写上：

```yaml
    smtpHost: smtp.example.com
    smtpPort: 465
    imapHost: imap.example.com
    imapPort: 993
```

只写 `user` 和 `pass` 时，默认连的就是 QQ 邮箱（`smtp.qq.com:465`、`imap.qq.com:993`）。

## 四、先写草稿，给你过目再发

这是推荐的发信方式，尤其发给别人的正式邮件。

你让 DSH 写信，它不会直接发出去，而是：

1. 把信原样写进你 QQ 邮箱的「草稿箱」
2. 给你一个链接：https://mail.qq.com/
3. 你打开链接，左边点「草稿箱」，最新那一封就是它
4. 觉得哪里不对就直接在网页上改，改完自己点发送

好处是：你看到的是真真正正躺在你邮箱里的信，格式、附件、收件人都对得上，不会出现“模型说发了其实没发”这种事。

## 五、定时发送

直接说时间，比如“明天早上 9 点把这封发给张三”。

它的工作方式：

- 任务先存在本地，插件在后台每分钟检查一次，到点就发
- **DSH 必须开着**才会准时发
- 如果到点的时候 DSH 是关着的，会在你下次打开 DSH 后立刻补发，返回值里会标 `late: true`，告诉你这封迟到了

## 六、常见问题

**问：提示授权码错误 / 登录失败？**

多半是填成了 QQ 密码，或者授权码已经失效。回邮箱后台重新生成一个，替换配置里 `pass:` 那一行，再重启 DSH。

**问：为什么 QQ 邮箱不能移动邮件？**

腾讯没对第三方软件开放“移动”和“复制”这两个指令，我们发过去会被直接拒绝（`[CANNOT] Not allow to move mail!`）。这是 QQ 的限制，不是插件坏了。要归档邮件只能在网页端手动拖。

**问：为什么搜索只能搜到最近的邮件？**

QQ 邮箱的搜索指令会忽略条件、把全部邮件都返回，等于失灵。所以插件改成自己下最近 500 封逐个比对，靠 `scan_limit` 可以调大，但越早的邮件就越可能搜不到。要精确搜索建议直接在网页端搜。

**问：附件下载失败？**

先确认那封邮件真的带附件，再确认输出目录存在、有写权限。文件名重复时插件会自动加序号，不会覆盖。

**问：发信报超时？**

QQ 的 SMTP 有时要等几十秒才回应。换网络、关掉 VPN 再试；多次失败就去邮箱后台看看是不是触发了发信频率限制。

**问：会不会自己偷偷把我邮件删了？**

不会。插件没有“删除邮件”的能力，只有标记和移动（移动在 QQ 上也用不了）。

## 七、安全提醒

- 授权码等于你邮箱的收发权限，**只放在本机配置文件里**，不要截图发人，不要提交到 Git 仓库。
- 定时任务的队列文件里存着信的正文（不含授权码），正文有敏感内容时注意那个目录别被别人看到。
- 怀疑授权码泄露了，就去邮箱后台重新生成一个，换掉配置里的那一行。
- 发信是真发，草稿是真进草稿箱，没有“演练模式”。要试就发给自己。

---

## 八、已知限制

- 不自动把读过的邮件标记为已读（需要的话明说，用 `mail_mark`）。
- 邮件正文里的远程图片不会自动下载。
- QQ 邮箱不支持移动 / 复制邮件。
- 只支持用账号密码（授权码）登录，暂不支持 Gmail 那种 OAuth 一键授权。
- 定时发送依赖 DSH 在运行。
